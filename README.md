# 나만의 파이썬 퀴즈 게임

## 1. 프로젝트 개요
파이썬 기초 문법과 객체지향 개념을 적용하여 터미널에서 동작하는 콘솔 퀴즈 게임을 구현한 프로젝트다. Git과 GitHub를 활용하여 버전 관리 및 브랜치 생성, 병합을 실습했다.

## 2. 퀴즈 주제 선정 이유
* **주제:** [운영체제 및 데이터베이스 핵심 개념]
* **이유:** [전공 학습 내용을 복습 목적]

## 3. 실행 방법
파이썬 3.10 이상의 환경에서 터미널을 열고 아래 명령어를 입력하여 실행한다.
```bash
python3 main.py
```

## 4. 기능 목록
프로그램은 다음과 같은 주요 기능을 제공한다.

- **퀴즈 풀기**: 저장된 퀴즈를 출제하고, 사용자 입력에 따라 정답/오답 여부를 알려주며 최종 점수를 계산한다.
- **퀴즈 추가**: 문제, 4개의 선택지, 정답 번호를 입력받아 새로운 퀴즈를 등록한다.
- **퀴즈 목록**: 현재 시스템에 저장된 모든 퀴즈 목록을 조회한다.
- **점수 확인**: 기록된 역대 최고 점수를 출력한다.

## 5. 파일 구조
📦 프로젝트 루트
┣ 📜 main.py       # 게임 메인 실행 루프, Quiz 및 QuizGame 클래스 코드
┣ 📜 state.json    # 상태 저장을 위한 JSON 데이터 파일
┗ 📜 README.md     # 프로젝트 문서

## 6. 데이터 파일 설명
경로 및 역할: 프로젝트 루트 디렉토리에 위치하며, 사용자가 추가한 퀴즈 목록과 달성한 최고 점수를 영구적으로 저장한다.
(참고. "answer: 정답 선택지의 인덱스(0부터 시작)")
