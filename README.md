# 나만의 파이썬 퀴즈 게임

## 1. 프로젝트 개요
파이썬 기초 문법과 객체지향 개념을 적용하여 터미널에서 동작하는 콘솔 퀴즈 게임을 구현한 프로젝트다. Git과 GitHub를 활용하여 버전 관리 및 브랜치 생성, 병합을 실습했다.

## 2. 퀴즈 주제 선정 이유
* **주제:** [운영체제 및 데이터베이스 핵심 개념]
* **이유:** [전공 학습 내용을 복습 목적]

## 3. 실행 방법
파이썬 3.10 이상의 환경에서 터미널을 열고 아래 명령어를 입력하여 실행한다.
```bash
python3 main.py
```

## 4. 기능 목록
프로그램은 다음과 같은 주요 기능을 제공한다.

- **퀴즈 풀기(랜덤 출제 및 문제 수 선택)**: 원하는 문제 수를 입력하면 저장된 퀴즈 중 무작위로 추출하여 출제한다. 사용자 입력에 따라 정답/오답을 판별하고 최종 점수를 계산한다.
- **힌트 기능**: 퀴즈 풀이 중 'h'를 입력해 힌트를 열람할 수 있으며, 힌트 사용 시 획득 점수가 0.5점으로 삭감된다.
- **퀴즈 추가**: 문제, 4개의 선택지, 정답 번호, 힌트를 입력받아 새로운 퀴즈를 등록한다.
- **퀴즈 목록**: 시스템에 저장된 퀴즈 목록을 확인하고, 원하는 퀴즈 번호를 선택해 삭제할 수 있다.
- **점수 및 히스토리 확인**: 기록된 역대 최고 점수와 플레이한 날짜, 획득 점수가 포함된 최신 기록 내역을 출력한다.
